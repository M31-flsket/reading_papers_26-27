
# 机器狗搭载机械臂控制系统

## 1. 项目简介

本项目是 Go2 Pro 四足机器狗开发项目的重要组成部分，主要研究如何将机械臂搭载到四足移动机器人平台上，构建具备移动能力与物体操作能力的移动操作机器人系统（Mobile Manipulation Robot）。

项目以 Unitree Go2 Pro 四足机器狗为最终搭载平台，以 Elephant Robotics myCobot 280 六自由度机械臂为当前开发对象，围绕机械臂底层控制、运动学建模、运动规划、视觉感知、目标定位以及机器人协同控制等方向开展开发。

项目最终希望实现：

- Go2 Pro 四足机器狗自主移动与定位。
- 机械臂自主运动与末端执行器控制。
- 机器人视觉感知与环境理解。
- 对目标物体进行识别、定位和抓取。
- 四足移动平台与机械臂之间的任务协同。
- 构建具备移动、感知和操作能力的机器人系统。

目前项目处于机械臂独立开发阶段，首先完成机械臂本体的控制系统搭建和基础功能验证，再逐步推进与 Go2 Pro 的硬件集成和软件协同。

---

## 2. 项目总体目标

本项目的总体目标是构建一个以 Go2 Pro 为移动底盘、以机械臂为操作执行机构的移动操作机器人平台。

整体系统可以划分为以下几个部分：

### 2.1 移动平台

以 Unitree Go2 Pro 四足机器狗作为移动平台，负责：

- 四足运动控制。
- 环境移动与导航。
- 机器人姿态与状态反馈。
- 携带机械臂及相关计算设备。

### 2.2 机械臂操作系统

以 myCobot 280 为当前研究对象，负责：

- 六自由度关节控制。
- 末端执行器控制。
- 正向运动学与逆向运动学。
- 机械臂运动规划。
- 物体抓取与操作。

### 2.3 视觉感知系统

围绕机械臂与移动平台的协同操作，逐步实现：

- 摄像头图像采集。
- 目标物体识别。
- 目标位置估计。
- 坐标系转换。
- 视觉引导抓取。

### 2.4 系统协同控制

最终建立 Go2 Pro 与机械臂之间的通信和控制机制，实现：

- 移动平台与机械臂状态交互。
- 移动与操作任务协调。
- 机器人运动过程中的安全约束。
- 面向具体任务的自主操作。

## 4. 软件开发架构

项目采用分层开发思路，逐步建立从底层硬件通信到上层自主操作的完整软件架构。

### 4.1 底层控制层

主要使用 Python 和 pymycobot SDK。

负责：

- 串口通信。
- 机械臂状态读取。
- 关节角度控制。
- 末端执行器控制。
- 底层运动指令管理。

### 4.2 机器人驱动层

建立自主机械臂驱动程序，对底层 SDK 进行封装。

负责：

- 统一机械臂控制接口。
- 关节限位检查。
- 运动状态检查。
- 异常处理。
- 状态反馈与运动控制。

### 4.3 ROS 通信与集成层

当前 Jetson Nano 原厂环境使用 ROS Melodic。

后续研究：

- 机械臂 ROS 节点开发。
- 机械臂状态话题发布。
- 机械臂运动指令订阅。
- Go2 与机械臂之间的通信。
- 多模块系统集成。

### 4.4 运动规划层

逐步研究：

- 机械臂正向运动学。
- 机械臂逆向运动学。
- 关节空间轨迹规划。
- 笛卡尔空间轨迹规划。
- MoveIt 运动规划。

### 4.5 视觉感知层

以 OpenCV 和相关视觉算法为基础，逐步研究：

- 图像采集与处理。
- 目标检测。
- 目标空间位置估计。
- 相机标定。
- 手眼标定。
- 视觉引导抓取。

### 4.6 任务决策与协同层

面向最终移动操作任务，研究：

- 任务分解。
- 移动与操作协调。
- 机械臂工作空间约束。
- 多设备状态管理。
- 自主抓取任务执行。

## 5. 开发路线与阶段规划

项目按照由单机控制到系统集成、由基础功能到自主操作的路线推进。

### 阶段一：机械臂基础控制

目标：建立自主机械臂控制项目，验证底层通信和基础运动能力。

主要任务：

- Jetson Nano 开发环境检查。
- 原厂系统与 SDK 分析。
- 串口通信测试。
- 机械臂状态读取。
- 自定义 Python 驱动开发。
- 单关节小幅度运动测试。
- 软件限位与异常处理。

当前进度：

**已完成基础通信、状态读取和 J1 单关节 5° 运动测试。**

详细记录：

- [阶段一：机械臂基础通信与运动控制](STAGE_01_BASIC_CONTROL.md)

### 阶段二：机械臂基础控制完善

目标：建立更加完整、可靠的机械臂控制接口。

主要任务：

- 六个关节分别进行小幅度运动测试。
- 多关节联合控制。
- 夹爪开合控制。
- 运动反馈与误差检测。
- 异常状态处理。
- 机械臂基础控制接口完善。

### 阶段三：机械臂运动学建模

目标：建立机械臂数学模型，为后续自主运动规划做准备。

主要任务：

- 机械臂结构分析。
- 连杆参数测量。
- DH 参数建模。
- 正向运动学求解。
- 逆向运动学求解。
- 末端执行器位姿控制。

### 阶段四：机械臂运动规划

目标：实现机械臂从当前位置到目标位置的自主运动。

主要任务：

- 关节空间轨迹规划。
- 笛卡尔空间轨迹规划。
- 轨迹平滑处理。
- 运动约束与碰撞检测。
- ROS 与 MoveIt 集成。

### 阶段五：视觉感知与自主抓取

目标：使机械臂具备感知目标并执行抓取的能力。

主要任务：

- 摄像头接入。
- 图像采集。
- 目标物体识别。
- 目标位置估计。
- 相机与机械臂坐标系转换。
- 手眼标定。
- 视觉引导抓取。

### 阶段六：机械臂与 Go2 Pro 硬件集成

目标：将独立开发的机械臂系统集成到 Go2 Pro 四足机器狗上。

主要任务：

- 机械臂安装结构设计。
- 机械臂与机器狗的空间布局。
- 供电方案设计。
- 通信接口设计。
- 计算平台与软件架构规划。
- 机械臂与机器狗联合调试。
- 整机安全性验证。

### 阶段七：移动操作与自主协同

目标：实现机器狗移动与机械臂操作之间的协同。

主要任务：

- Go2 运动控制与机械臂控制接口集成。
- 移动平台与机械臂状态交互。
- 目标物体定位。
- 移动到目标附近。
- 机械臂自主抓取。
- 移动与操作任务协调。
- 完整移动操作任务验证。

## 7. 项目开发原则

1. 优先复用原厂系统和 SDK，避免在初期破坏已有环境。
2. 采用分层设计，降低底层硬件控制与上层算法之间的耦合。
3. 先完成单机功能验证，再推进多设备集成。
4. 运动控制优先考虑安全性、稳定性和可重复性。
5. 每个开发阶段保留独立的 Markdown 文档，记录开发目标、实现过程、测试结果和遗留问题。
6. 重要功能必须通过实际硬件测试验证，不能仅以程序编译成功作为完成标准。

## 8. 项目最终目标

本项目最终希望实现一套基于 Unitree Go2 Pro 的移动操作机器人系统。

系统以 Go2 Pro 为移动平台，以机械臂作为操作执行机构，结合视觉感知、运动规划和任务决策，使机器人不仅能够在环境中移动，还能够主动识别目标、接近目标并完成抓取等操作任务。

最终形成：

**四足移动平台 + 六自由度机械臂 + 视觉感知 + 自主运动规划 + 协同控制**

的完整移动操作机器人系统。
