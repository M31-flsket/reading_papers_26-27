
# Go2 Pro Development —— 四足机器狗项目开发

本目录用于记录 Unitree Go2 Pro 四足机器狗的实际项目开发过程，包括已有功能移植、外部计算平台接入、语音交互系统开发、机械臂集成及相关功能扩展。

目前项目主要分为两个开发方向：

1. **语音交互系统移植**：将 Go2 EDU 版本已经实现的语音交互功能移植到 Go2 Pro，借助 Jetson 外接开发板实现语音采集、处理及机器人控制。
2. **机械臂集成与功能开发**：研究并实现机械臂在 Go2 Pro 平台上的安装、控制及协同应用。

---

## 01. Project Overview —— 项目概述

### 1.1 项目目标

基于现有 Go2 EDU 版本的语音交互项目，将已经开发完成的语音识别、语音指令处理及机器人控制等功能适配到 Go2 Pro 平台。

由于 Go2 Pro 当前没有可直接使用的 USB 接口，无法按照 EDU 版本原有的硬件连接方式直接接入麦克风，因此计划采用外接 Jetson 开发板的方案。

整体开发思路：

- 利用 Jetson 开发板连接麦克风，负责音频采集及语音处理。
- 移植和适配 EDU 版本已有的语音交互程序。
- 通过网络建立 Jetson 与 Go2 Pro 之间的通信。
- 将语音识别和指令解析结果发送给机器狗。
- 调用机器狗控制接口，实现语音指令与机器人动作的联动。
- 实现机器狗语音反馈及相关交互功能。

### 1.2 硬件平台

| 设备 | 用途 | 当前情况 |
|---|---|---|
| Unitree Go2 Pro | 四足机器人主体 | 项目开发平台 |
| Jetson Nano B01 | 外接计算与语音处理平台 | 已有设备，待重新部署系统 |
| 麦克风 | 语音输入 | 计划连接 Jetson |
| Go2 Pro 扬声器 | 语音反馈 | 待完成适配与验证 |
| 机械臂 | 扩展机器人操作能力 | 后续开展集成 |

## 02. Voice Interaction Migration —— 语音交互系统移植

### 2.1 原始项目与技术参考

目前已有 Go2 EDU 版本的语音交互项目，其基本功能已经由其他开发人员实现。

**原始 GitHub 仓库：**

https://github.com/drk-cyber/unitree_go2_voice

本项目优先研究和复用该仓库中已经实现的程序，避免重复开发已有功能。

目前已了解到的原始项目技术架构：

| 模块 | 使用技术 | 主要作用 |
|---|---|---|
| 音频采集 | USB 麦克风 | 获取用户语音 |
| 语音识别 ASR | SenseVoice、sherpa-onnx | 本地语音识别 |
| 指令处理 | 唤醒词及固定指令匹配 | 识别用户控制意图 |
| 机器人通信 | unitree_webrtc_connect | 与机器狗通信及控制 |
| 语音合成 TTS | MeloTTS | 将反馈内容转换为语音 |
| 语音输出 | Go2 扬声器 | 播放语音反馈 |

原始项目中已知的重要程序入口：

- `voice_control_board.py`：语音控制程序入口。
- `voice_control_board_runtime.py`：核心运行逻辑。

注意：目前掌握的是原始项目的技术架构和程序入口，尚未完成对所有模块的实际移植和运行验证。

### 2.2 当前移植方案

由于 Go2 Pro 无法直接按照原 EDU 版本的方式连接 USB 麦克风，因此需要调整原有系统架构。

计划采用以下结构：

```text
             用户语音输入
                   |
                   v
          麦克风（外接设备）
                   |
                   v
          Jetson Nano B01
                   |
          +----------------+
          | 音频采集       |
          | 语音识别 ASR   |
          | 指令解析       |
          | 语音合成 TTS   |
          +----------------+
                   |
                   v
             网络通信
                   |
                   v
              Go2 Pro
                   |
          +----------------+
          | 接收控制指令   |
          | 执行机器人动作 |
          | 语音反馈输出   |
          +----------------+
```

具体实施过程中，需要根据原始代码的运行依赖、硬件接口和通信方式进行适配，不直接假定 EDU 与 Pro 的硬件接口完全一致。
