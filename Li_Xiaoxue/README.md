# 李晓雪的个人科研与项目开发记录

本目录用于记录个人在科研学习、项目开发和技术研究过程中的工作进展，主要分为两个方向：**Go2 Pro 四足机器狗项目开发**和**航空航天相关科研论文研读**。

通过持续整理项目开发过程、技术资料、论文阅读笔记和阶段性研究成果，形成个人长期的科研与技术开发档案。

## 01. Go2 Pro Development —— 四足机器狗项目开发

本方向主要围绕 Unitree Go2 Pro 四足机器狗开展实际项目开发与功能移植工作。

目前的核心任务是基于现有 Go2 EDU 版本已经实现的语音交互功能，将相关程序和技术方案移植到 Go2 Pro 平台，并结合外部计算设备实现机器狗的智能交互与功能扩展。

主要开发内容包括：

### 1. 语音交互系统移植
- 研究 Go2 EDU 版本已经实现的语音交互系统。
- 分析现有语音识别、语音控制和智能对话相关程序。
- 研究原有代码的运行机制及模块之间的调用关系。
- 将已有语音交互功能适配并移植到 Go2 Pro 平台。
- 完成语音识别、指令解析和机器狗动作控制的功能整合。

### 2. Jetson 开发板接入与网络通信
- 重新部署 Jetson 开发板系统及相关开发环境。
- 实现麦克风等外部音频设备接入。
- 研究 Jetson 开发板与 Go2 Pro 之间的网络通信机制。
- 实现语音处理程序与机器狗控制系统之间的数据交互。
- 完成外部设备发送控制指令及机器狗执行动作的通信链路。

### 3. 机械臂集成与功能开发
- 研究适用于 Go2 Pro 的机械臂硬件及安装方案。
- 实现机械臂与机器狗平台的集成。
- 研究机械臂控制接口及通信方式。
- 开发机械臂运动控制与相关功能。
- 探索机器狗移动能力与机械臂操作能力的协同应用。

### 4. 项目代码开发与系统集成
- 整理和移植已有项目源代码。
- 根据 Go2 Pro 平台进行程序适配与修改。
- 在 Ubuntu 虚拟机开发环境中进行代码编写、调试和测试。
- 整理项目依赖、配置文件及相关程序。
- 完成代码打包、部署及向目标设备传输。
- 记录开发过程中遇到的问题、解决方案及阶段性成果。

详细开发记录见：[Go2 Pro Development](./Go2_Pro_Development/README.md)。

## 02. Paper Research —— 科研论文研读与研究

本方向主要围绕个人未来的科研发展方向开展学术论文阅读、技术调研和研究课题探索。

目前计划以航空航天相关领域为主要研究方向，结合软件工程专业背景及计算机技术，逐步确定适合自己的具体科研课题。

现阶段重点关注航空航天领域与计算机技术、人工智能及嵌入式系统相结合的研究方向。

### 1. 航空航天相关研究
- 航空航天领域前沿技术与发展趋势。
- 星载计算平台及相关软硬件系统。
- 航天器嵌入式系统与软件设计。
- 星载人工智能及边缘计算。
- 航天器自主感知、智能决策与信息处理。
- 航天任务中的计算机系统与智能化应用。

### 2. 学术论文阅读与整理
- 收集与研究方向相关的国内外学术论文。
- 整理论文的研究背景与核心问题。
- 分析论文采用的关键技术、算法和系统架构。
- 研究论文中的实验设计、数据集及评价指标。
- 总结论文的创新点、研究成果与不足。
- 形成中文论文阅读笔记和个人研究思考。

### 3. 科研选题与论文研究
- 跟踪相关领域的最新研究成果。
- 对比不同研究方向的技术路线。
- 寻找现有研究中值得进一步探索的问题。
- 结合自身专业背景和技术能力确定研究切入点。
- 探索具有实际研究价值和创新性的科研课题。
- 逐步开展实验设计、技术验证和学术论文撰写。

具体研究方向和科研选题将根据后续文献阅读、导师指导及实际研究进展逐步明确。

详细研究记录见：[Paper Research](./Paper_Research/README.md)。
